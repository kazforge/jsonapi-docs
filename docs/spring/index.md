# Spring integration

The first approved guide is for **Spring WebMVC 0.1.0**, published independently of Core.

- [Spring WebMVC 0.1.0 documentation](0.1.0/index.md)

Requires Java 21+, Spring Framework 7.0.9+ (7.0.x), and the published Core 0.4.0 API/query baseline. The adapter is JSON-runtime-neutral; Jackson 3 is the verified application-supplied runtime.
